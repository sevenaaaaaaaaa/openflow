# Demo 权限设计（DEMO-ACCESS）

> 目标：外部用户能自助申请、拿到一个**只读但可体验**的演示空间；运营能一键开通、看清状态、到期回收，存储不失控。
> 模型（已定）：只读 + 允许"看得见效果但不落库"的模拟动作；**90 天**到期 → 冻结 7 天 → 删除；续期只能管理员改；**每个客户最多 1 个空间**。

## 1. 申请入口

复用现有 TOB 表单 `/enterprise.php`，不新建页面。改动只有三处：

1. 增加"申请类型"选项：咨询 / 演示；选演示时展示必填项（企业名、联系人、企业邮箱、用途）。
2. 提交后按邮箱域名去重：同域名已有空间 → 转人工；否则进入自动预审。
3. 线索继续走现有落盘 + 通知（`leads.csv` 兜底），只是多一个"演示"标记，便于运营筛选。

## 2. 审核与开通

| 环节 | 规则 |
|---|---|
| 自动预审 | 字段完整 + 企业域名邮箱（非公共邮箱）+ 未命中黑名单 + 无现存空间 → 置"待开通" |
| 人工兜底 | 其余进"待审核"，1 个工作日内处理，超时高亮 |
| 开通 | 后台**一键开通**：建空间 → 写种子 → 生成邀请码 → 设到期（+90 天）→ 发邮件 |
| 凭据 | 一次性邀请码（7 天有效、首次使用绑定会话）；邮件模板 + 后台可复制；不发明文密码 |
| 去重 | 同一企业邮箱域名最多 1 个空间，第二单转人工 |

## 3. 只读与模拟边界

| 入口 | 处理 |
|---|---|
| 内容保存 / 站点设置 | 拒绝，提示"演示环境只读" |
| 上传 | 拒绝（不落盘，避免配额失控） |
| 表单提交 | **模拟**：走完整校验，返回成功文案并标注"演示不会真实发送" |
| 自动化 / 跑一轮 | **模拟**：隔离沙箱执行，结果仅当前会话可见，结束清空 |
| 订单 / 支付 | 拒绝，只展示示例数据 |
| 外部副作用（发信、webhook、第三方写） | 一律不触发 |

配套：模拟动作按会话限速 + 全局每日上限；种子数据可一键重建。

## 4. 生命周期

| 时点 | 动作 |
|---|---|
| T0 | 开通（+90 天），发邀请码 |
| T-7 | 提醒运营（可选抄送客户） |
| T0 到期 | 冻结：只读保留，页面横幅提示可联系续期 |
| T+7 | 删除空间（先归档快照），写审计记录 |

续期：**只在管理员入口改到期日**，不开放客户自助。手动删除随时可用。

## 5. 管理入口（信息架构）

列表字段：客户 / 子域 / 状态 / 开通日 / 到期日 / 存储占用 / 最近访问 / 邀请码状态。
操作：开通、续期（改到期日）、冻结、恢复、删除、复制邀请码、重发邮件。
审计：谁在何时改了什么（开通、续期、冻结、删除各一条）。
告警：到期未回收数量、总量水位、单个空间超配额。

## 6. 配额与存储

- 每空间：数据目录 + 上传上限（演示只读，上传应为 0，上限只作兜底）。
- 种子固定体积，可重建；空间之间互不影响。
- 池级水位告警；到期未回收单独计数，避免"只开不关"。

## 7. 现状差距（已核实）

- 多租户只实现"按主机名切数据目录"，没有开通/管理/回收界面 → 管理入口要新建。
- 没有全局只读模式；只读要按入口逐项实现并验证 → 清单见第 3 节，必须逐条实测。
- 现有 `bin/cleanup-demo.php` 只清早期 demo 实体，不是空间级回收 → 回收逻辑需重写。
- 现有 3 个 Release 均为 Draft，与本项无关但同属对外链路，见 G3。

## 8. 验收（全链路，缺一不算）

1. 表单提交演示申请 → 自动预审进入待开通。
2. 后台一键开通 → 邮件/复制拿到邀请码 → 打开演示空间。
3. 尝试保存内容、上传、改设置、支付：全部被拒。
4. 提交表单、跑一轮自动化：有"模拟"结果，且刷新后不残留。
5. 改到期日 → 状态与提醒随之变化。
6. 到期冻结 → 再删除：空间消失、归档存在、审计有记录。

## 附录：申请表单字段映射（复用 /enterprise.php）

现有字段：company、industry、size、plan_type、budget、contact_name、email、phone、note，另有蜜罐 website。

新增两个字段（不新建页面）：

| 字段 | 取值 | 用途 |
|---|---|---|
| intent | 咨询 / 演示 | 决定后续流程；选「演示」时必填企业邮箱与用途 |
| demo_use | 一句话用途 | 运营判断种子数据与演示重点 |

规则：
- 邮箱域名去重（同域名已有空间 → 转人工）；公共邮箱域名直接转人工。
- 线索打标：CSV 增加一列 intent；通知主题加 [DEMO] 前缀，便于筛选。
- 提交后无论是否通过，都回同一句「1 个工作日内联系」，不暴露审核规则。
