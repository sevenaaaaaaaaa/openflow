# OpenFlow v2.1 Roadmap — OPC 商业化核心

> 版本：v2.1 规划 · 前提：v2.0/v2.0.1 已交付跨形态 + 核心业务闭环 + AI 渗透
> 主题：把会员/分销/生态/商业从「能记数据」变成「能帮 OPC 赚钱」

---

## 〇、现状诊断（四个模块的真实深度）

| 模块 | 现有 | 缺什么（为什么帮不了 OPC 赚钱） |
|---|---|---|
| **会员** | 240 行·计划/权益/额度 | 无付费墙联动·无升级路径 UI·无会员专属内容·无自动续费·无到期提醒 |
| **分销** | ApiAffiliate 197 行·分成政策 82 行 | 无推荐码生成·无点击→注册→成交归因·无佣金结算/提现·无分销商面板 |
| **生态市场** | 235 行·资产/搜索/统计 | 无定价体系·无收入分成·无上架审核流·无买家评价·无市场推广位 |
| **商业中心** | ShopSystem + 241 行·数字商品 | 无购物车·无订阅计费(月/年自动续费)·无发票/收据·无多币种·无转化漏斗 |

**核心矛盾**：这四个模块都是「数据结构在、但商业化逻辑断链」——有订单但没有转化漏斗、有分成政策但没有分销追踪、有会员计划但没有付费触发、有市场但没有交易闭环。

---

## 一、v2.1 主线：三条商业化闭环

### 闭环 A · 直接收钱（商城 → 支付 → 订单 → 交付）
> OPC 卖课/卖模板/卖咨询 → 收款 → 自动交付

| # | 事项 | 具体做什么 | 依赖 |
|---|---|---|---|
| A1 | **订阅计费** | 月/年自动续费 + 到期提醒 + 续费邮件 + 取消流程 | SubscriptionSystem 扩展 |
| A2 | **购物车** | 多商品加入购物车 → 统一结算 → 优惠码 → 单笔支付 | ShopSystem 扩展 |
| A3 | **发票/收据** | 支付成功自动生成 PDF 收据 + 邮件发送 | 新增 |
| A4 | **会员付费墙** | 会员等级 ↔ 内容门禁（文章/课程/下载）→ 未登录→付费引导页 | MembershipSystem + PaidContent 联动 |
| A5 | **升级路径** | 免费→付费→高级的升级推荐（AI 洞察告诉你该推谁升级） | + CdpSystem |
| A6 | **转化漏斗** | 访客→注册→加购→支付→复购 全链路可视化 | + CdpSystem + DashboardSystem |

### 闭环 B · 分销放大（推荐 → 归因 → 佣金 → 提现）
> OPC 的学员/粉丝帮你卖 → 自动追踪 → 分成

| # | 事项 | 具体做什么 | 依赖 |
|---|---|---|---|
| B1 | **推荐码体系** | 每个分销商一个推荐码/链接 → 点击埋 UTM → 注册/成交自动归因 | ApiAffiliate 重构 |
| B2 | **分销商面板** | 我的推荐链接 · 我的成交 · 我的佣金 · 提现申请 | 新增 admin/affiliate-panel.php |
| B3 | **佣金结算** | 成交→自动算佣金→累计→到门槛→标记可提现→人工确认打款 | CommissionPolicy 扩展 |
| B4 | **分销等级** | 普通分销→高级分销→合伙人（不同分成比例） | + CommissionPolicy |
| B5 | **分销素材** | 一键生成带推荐码的海报/文案/链接 | + ApiAffiliate + CanvasSystem |

### 闭环 C · 生态交易（创作者上架 → 买家购买 → 平台分成）
> OPC 或其学员把 Skill/模板/主题上架 → 别人买 → 平台分成

| # | 事项 | 具体做什么 | 依赖 |
|---|---|---|---|
| C1 | **市场上架定价** | Skill/模板/主题 设定价格 → 上架审核 → 展示 | MarketplaceSystem 扩展 |
| C2 | **市场购买** | 点购买 → 走 A 闭环（购物车/支付）→ 自动交付/安装 | + ShopSystem |
| C3 | **收入分成** | 平台抽成（可配）→ 创作者收入 → 提现 | CommissionPolicy 联动 |
| C4 | **评价体系** | 买家评分/评论 → 影响排序/推荐 | 新增 |
| C5 | **市场首页** | 精选/热门/新品 推荐位 → 转化导向 | + FeaturedSystem |

## 二、辅助能力（支撑三条闭环）

| # | 事项 | 为什么需要 |
|---|---|---|
| D1 | **价格与货币** | 后台统一定价管理 + 多币种支持（至少 CNY/USD） |
| D2 | **支付渠道扩展** | 现有 xfpay 基础上加微信支付/支付宝/Stripe（OPC 可能要收美元） |
| D3 | **邮件自动化（商业化）** | 弃购提醒/续费提醒/升级推荐/欢迎序列——已有 MA 但缺商业化模板 |
| D4 | **AI 商业助手** | 「哪些线索该推升级」「哪个分销商在流失」「定价建议」——AI 渗透到商业化 |
| D5 | **合规** | 退款政策页/服务条款/隐私政策模板（OPC 需要但容易忽略） |

## 三、优先级与节奏

### 第一批（P0 · 直接让 OPC 能收钱）
- A1 订阅计费（自动续费）
- A4 会员付费墙
- A2 购物车
- B1 推荐码体系

### 第二批（P1 · 让 OPC 能规模化收钱）
- B3 佣金结算
- C1 市场上架定价
- C2 市场购买
- A6 转化漏斗

### 第三批（P2 · 让 OPC 能持续赚钱）
- A5 升级路径
- B2 分销商面板
- C3 收入分成
- D4 AI 商业助手
- D3 邮件自动化（商业化）

### 第四批（P3 · 完善体验）
- A3 发票/收据
- B4 分销等级
- C4 评价体系
- D2 支付渠道扩展
- D5 合规模板

---

## 四、不做的事（明确排除）

- 不做第三方 SaaS 市场（不跟 Shopify App Store / WordPress.org 竞争）
- 不做多租户 SaaS 化（仍以单站部署为主）
- 不做虚拟货币/区块链
- 不做自动扣款（提现人工确认，安全第一）

---

## 五、验收标准（v2.1 什么叫"做完"）

1. OPC 能在 30 分钟内配置好：会员计划 → 付费墙 → 支付 → 自动交付
2. OPC 能一键生成推荐链接 → 追踪到成交 → 自动算佣金 → 导出提现
3. 创作者能在市场上架 Skill → 有人买 → 收到分成
4. 所有支付/佣金/订阅有审计留痕 + AI 可解读转化数据
5. 契约测试全绿 + 冒烟无回归

---

## 六、与 v2.0 的关系

v2.0/v2.0.1 解决了「**能不能用**」——跨形态、核心业务闭环、AI 渗透、功能诚实。
v2.1 解决「**能不能赚钱**」——商业化三条闭环 + 辅助能力。

两者共享同一套 PHP 后端/CDP/MA/CRM 基础，v2.1 的商业化能力建在 v2.0 已有的底座上。
