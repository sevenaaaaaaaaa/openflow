# AITIPS Flow 运行基线

> 基线名称：`aitips-flow-v1`。运行 `php tests/flow_baseline.php` 可重复生成机器可读报告 `artifacts/flow-baseline.json`。

## 测量边界

阶段 0 先保护现有确定性 Flow，不用尚未实现的 Loop 指标评价它。当前自动基线覆盖：

| 维度 | 契约 | 失败意味着什么 |
|---|---|---|
| 事件与插件隔离 | CDP 事件可过滤，插件异常不打断后续回调 | 扩展可能拖垮主业务 |
| CRM → Flow 联动 | 阶段变化只触发一次并保留正确前后状态 | 销售状态无法可靠进入流程 |
| 画布条件 | 上下文与 CRM 字段可确定解析，空值安全降级 | 用户设计的分支不可预测 |
| 画布动作 | 标签、评分、阶段和 Webhook 动作契约稳定 | Flow 节点不能可靠落地 |
| 成交反馈 | 成交信号回写画像与增长真相 | Sell 无法回到 Insight |
| 支付钩子 | 支付内容事件与插件联动保持兼容 | 商业 Flow 可能断裂 |
| 事务恢复 | SQLite 与 JSON 跨存储写入成功一致、失败回滚 | 关键动作可能留下半成品 |
| 投递可靠性 | MCP 写入、Webhook 重试与 A/B 判断契约稳定 | 外部动作可能丢失或误报 |

## 首次基线结果

本地环境：PHP 8.5.9。

- 8 个基线契约全部通过，成功率 100%；
- 总耗时约 1.80 秒；
- 单项 p95 约 1.41 秒；
- 阶段 0 首次完整独立契约套件 77/77 通过，总耗时约 22.13 秒；后续新增契约会自动进入同一阻断套件。

耗时用于观察趋势，不作为跨机器硬阈值；成功率是阻断条件。CI 每次生成 JSON 报告并保留 30 天，后续可按相同 runner 比较退化。

## 尚未自动化的业务基线

以下指标需要真实使用路径和样本，不能用代码断言伪造：

- 用户从空白画布建立一条 Flow 的操作步数和完成时间；
- Flow 触发成功率、动作执行成功率和失败恢复时间；
- 从留资、跟进、报价到成交的实际转化率；
- Copilot 为高阶用户节省的配置步骤；
- 每条 Flow 的渠道成本、AI 成本和增量收入。

阶段 1 只定义这些指标的事件和对象归属；有真实数据后再建立数值基线。
