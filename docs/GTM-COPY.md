# 文案替换表（不动模块）

> **约束**：模块、顺序、数量、槽位一个不改，只换词。
> 每一条都是「现有 → 建议 → 为什么」，可以逐条采纳，也可以只挑几条。
>
> 定位与事实边界见 `docs/GTM.md`（那份里我自作主张重排过信息架构，
> **已作废**——以本文的真实模块为准）。

---

## 通篇的一个诊断

现有文案**不是句子写得不好，是没有一条贯穿的情绪线**。
每个模块各自用了不同的说服方式（数据、框架、功能、引语），但读者从上到下走完，
情绪没有递进——所以显得"平"。

还有一件更可惜的事：**全页最有力的那句话被埋在副标题里**——

> 「你不缺怎么做，你缺该做什么。」

这句话把整个产品的存在理由说完了，而且它是**用户视角**（说的是你的处境，
不是我的功能）。现在它躺在 Hero 副标题的第一个逗号前，几乎没人读到那儿。

**这份替换表做的就两件事：**
1. 把最强的话放到最显眼的位置
2. 给八个模块一条递进的线：
   **认领他的处境 → 说破他卡在哪 → 给出机制 → 证明可行 → 把门槛降到最低**

## ① Hero

| 槽位 | 现有 | 建议 |
|---|---|---|
| eyebrow | 芭乐派 · 帮一人公司设计 Agent 能跑的增长系统 | **芭乐派 · 给一人公司的增长系统** |
| h1 第 1 行 | 设计你的 | **你不缺** |
| h1 第 2 行 | 增长系统 | **怎么做，** |
| h1 第 3 行 | 让 Agent 替你 | **你缺** |
| h1 第 4 行（强调色） | 跑流程 | **该做什么** |
| 副标题 | 你不缺怎么做，你缺该做什么。OpenFlow 是芭乐派增长操作系统的开源底座：自动爬取行业信号、生成内容草稿、主动触达转化——让 Agent 跑流程 | **市面上的增长工具都默认你有一支团队。芭乐派做的是另一套：它自己爬信号、自己出草稿、自己盯该跟进谁——你只做判断，不做事。** |
| 主按钮 | 免费开始 | **免费开始（开源）** |
| 次按钮 | 查看平台演示 | **先看它一天干什么** |
| 信任条 | Seven · 十年增长操盘 · 核心能力永久开源 · 自生长 AI Engine | **Seven · 十年增长操盘 · 核心能力永久开源 · 数据在你自己的服务器** |

**为什么这么改**

- **h1 换成那句被埋没的话。** 「设计你的增长系统」是在给用户派活——他要是有精力设计
  系统，就不会来了。而「你不缺怎么做，你缺该做什么」直接说中他的处境，
  而且**第一人称是"你"不是"我们"**。
- **「跑流程」是内部词。** 用户脑子里没有"流程"这个对象，他脑子里是"我干不完"。
- **副标题承接 h1**：既然 h1 说了"你缺该做什么"，副标题就要回答"那谁来做"。
  顺手把差异化（别人默认你有团队）放进去——这是全站最该反复说的一句。
- **信任条把「自生长 AI Engine」换掉**：这是自造名词，且"自生长"不好证明。
  换成「数据在你自己的服务器」——这是**可验证的**，也是开源用户最在意的。

> ⚠️ Hero 那张画布（五层信号流）**不要动**。它是首页最贵的资产——
> 它让"Agent 替你跑"这句话变成看得见的东西，比任何一句文案都有说服力。

| 03 标签 | AI Engine · 每 6h | **AI Engine · 周期你定** |

**为什么这么改**

- 三个标题原本全是**动宾抽象词**（连接 / 设计 / 驱动），读完不知道自己要干嘛。
  改成三句**大白话**，而且第三步「然后你就可以去干别的了」是**收益不是动作**——
  三步的终点应该是用户得到什么，不是他还要做什么。
- ⚠️ **「每 6 小时」必须改掉。** 我核过代码：周期取决于用户自己配的 cron，
  不是内置固定值。写死一个数字，用户装完发现不是这样，第一印象就毁了。
  改成「周期你定」反而是个卖点。
- 「自生长 AI Engine」里的"自生长"同样不好证明，正文里去掉，标签保留 AI Engine。

**为什么这么改**

现在四个场景说的**是同一句话**（"自动爬取…你只需要判断"），
读者点了四个 tab 发现内容一样，反而更不信。

改法是**每个场景先认领他此刻的具体困境**（不知道写什么 / 卡在转化 /
重复运营吃精力 / 不想被绑住），再给对应的解法。
四个场景的第一句话必须**互不相同**，这才是 tab 存在的理由。

关于页最该展示的就是取舍，而不是能力。

# 采纳建议

如果时间有限，**按这个顺序改，前三条最值**：

| 顺序 | 改什么 | 为什么最值 |
|---|---|---|
| 1 | 首页 h1 换成「你不缺怎么做，你缺该做什么」 | 一句话的改动，撬动整页的说服力 |
| 2 | 三步闭环里「每 6 小时」改成「周期你定」 | **这是不实表述，属于风险不是优化** |
| 3 | 对比表那五个「原生」换成五句具体好处 | 目前那一列信息量为零，改完立刻有说服力 |
| 4 | 四个场景 tab 的第一句改成各不相同的困境 | 现在四个 tab 内容雷同，反而减分 |
| 5 | 洞察那句加上「不是 37 条线索，是今天该联系哪 3 个」 | 全站最容易被记住的一句话 |
| 6 | 其余页面的 h1 | 单页收益，可以慢慢来 |

> 另：`docs/GTM.md` 里我重排过的「信息架构」和「逐页文案」两节**作废**，
> 以本文为准。那份里的**定位屋**和**可以说 / 不能说**两节仍然有效——
> 尤其后者，「Platform Intelligence」「唯一」「自动修」三处旧表述该从线上撤掉。
