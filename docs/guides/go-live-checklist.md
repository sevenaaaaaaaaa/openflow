# 上线验收清单

> 五项全绿才算上线。每项都给"怎么验"，不要用"应该好了"代替。

| # | 项目 | 怎么验 | 不通过时先看 |
|---|---|---|---|
| 1 | 域名可访问（HTTPS） | 外网打开 https://你的域名/，200 且标题正确 | DNS、证书、反代头 |
| 2 | 后台可登录 | 打开 /xmp/login，用管理员登录 | 安装是否完成、data 目录是否可写 |
| 3 | 能发布内容 | 后台新建一篇并发布，前台能看到 | 权限、data 目录可写 |
| 4 | 能收到留资 | 前台提交一次表单，后台能看到记录 | 表单配置、邮件或存储通道 |
| 5 | 定时任务与备份就绪 | cron 有成功记录；备份能解开；知道怎么回滚 | cron 是否真在跑、备份路径 |

## 三条自查命令

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://你的域名/        # 期望 200
curl -s https://你的域名/ | grep -o '<title>[^<]*' | head -1     # 期望站点标题
ls -lh data/ uploads/ | head                                       # 数据目录存在
```

## 上线后 24 小时

- 看一眼错误日志 data/php-error.log。
- 确认 cron 至少成功跑过一轮。
- 把备份复制到另一台机器或对象存储（同盘备份等于没有备份）。
