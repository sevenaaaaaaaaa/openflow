# 面板部署（宝塔 / 1Panel）

> 适用：想少敲命令、用面板管理站点与证书。两条路径本质都是"PHP 站点 + 仓库根目录"，差异在面板操作位置。

## A. 宝塔面板

1. 新建站点：域名填自己的域名，根目录选**仓库根**（不是它的子目录）。
2. PHP 版本选 8.1+，安装扩展：pdo_sqlite、sqlite3、gd、mbstring、curl、openssl、fileinfo。
3. 伪静态：把仓库里 `deploy/baota-rewrites.conf` 的规则贴进站点伪静态（面板默认规则不包含本项目路由）。
4. 目录权限：`data/` 与 `uploads/` 属主设为 www，目录 755、文件 644。
5. 关闭"防跨站攻击（open_basedir）"或把仓库根加进白名单，否则跨目录读写会被拦。
6. 计划任务：新增 Shell 或 URL 任务，每分钟访问 `/api/cron.php`。
7. SSL：面板一键 Let's Encrypt，开强制 HTTPS。

## B. 1Panel

1. 应用商店安装 PHP 运行环境（8.1+），装同样的扩展。
2. 网站 → 新建网站：类型选 PHP，根目录指向仓库根。
3. 伪静态：贴与宝塔相同的规则（来源同上）。
4. 目录权限与防跨站同宝塔：开放 `data/` 与 `uploads/` 的读写。
5. 计划任务：每分钟请求 `/api/cron.php`。
6. SSL：1Panel 的证书申请，或使用已有证书。

## C. 两家共同的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 除首页外全 404 | 伪静态没贴或没生效 | 贴项目规则并重载 Web 服务 |
| 500 | PHP 版本低或扩展缺 | 版本 8.1+，补齐扩展 |
| 后台保存无效 | `data/` 属主不是 www | 改属主后重试 |
| 上传失败 | open_basedir 拦截 | 加白或关闭防跨站 |
| 面板备份缺数据 | 备份只含站点目录 | 单独定时备份 `data/` 与 `uploads/` |
| 升级后面板打不开 | 代码覆盖到子目录或权限被改 | 根目录指回仓库根，重设属主 |

## D. 验收

- 首页 200 且标题正确；`/xmp/login` 可登录。
- 后台上传一张图片，前台能看到。
- 计划任务有一轮成功记录。
