# OpenFlow 产品北极星

> 本文定义长期不变的产品边界。具体能力、任务和里程碑见 `FLOW-LOOP-ROADMAP.md`。

## 一句话

**OpenFlow 是一套基于 TIPS、同时支持 Flow 与 Loop 的开源增长操作系统。**

它把用户触达、用户洞察、个性化运营和销售增强连接在同一套数据与业务能力上：有经验的人可以用 Flow 精确设计和稳定执行；缺少经验或人力的人可以用 Loop，让 TIPS Agent 在明确边界内组合能力、验证策略并持续优化。

## 不变的 TIPS 业务模型

- **Touch**：建立有效触达，让正确的人进入业务。
- **Insight**：从真实行为与成交结果中形成证据和判断。
- **Personalize**：对不同的人，在合适的时机采取不同动作。
- **Sell**：推动成交、交付和复购，并把成功与失败回流洞察。

TIPS 既是产品的信息架构，也是 Flow 的能力分类、Agent 的推理边界和完整工作流的质量标准。任何增长方案都必须说明触达谁、依据什么判断、如何差异化运营、怎样产生业务结果，以及结果如何回流。

## 两种长期并存的运行范式

### Flow · AITIPS Copilot

人掌握策略，使用节点、画布、规则和分支设计流程；AI 作为 Copilot 帮助搭建、检查、生成和优化；系统按照批准的流程确定性执行。

Flow 解决“把已知方法稳定执行”，适合成熟 SOP、高阶用户，以及交易、交付、通知等强调可预测性和合规性的业务。

### Loop · TIPS Agent

人定义目标、资源、预算和风险边界；Agent 读取真实业务状态，按 TIPS 制订策略，调用 Skills 与成熟 Flow，在 Harness 和 Policy 约束下执行或请求审批，再依据业务结果进入下一轮。

Loop 解决“知道想要什么，但不知道最佳路径”，适合跨模块协调、动态试验，以及缺少专职增长经验和人力的用户。

Loop 不是无限调用模型。它必须具备 Goal、State、Skills、Harness、Policy、Evaluation、Memory 与 Stop Conditions，并以真实业务结果而非模型自评判断效果。

## 两者没有高低之分

- Flow 不会被 Loop 淘汰；确定性业务永远需要可检查、可预测的流程。
- Loop 不应退化成画布上的 AI 按钮；它必须能够基于反馈形成和调整策略。
- 成熟 Flow 可以成为 Agent 可调用的可靠 Skill。
- 经过多轮验证的 Loop 可以固化为新的 Flow。
- 同一业务对象在两种模式中共享数据、权限、审计和执行能力，不维护两套实现。

由此形成产品的经验飞轮：

```text
人的经验 → Flow → Agent 的可靠能力 → Loop 组合与试验
        ↑                              ↓
        └────── 稳定策略固化为 Flow ──┘
```

## 产品首先服从业务

OpenFlow 不以 AI 覆盖率或交互新颖程度判断进步，而以业务实用性、稳定性和兼容性判断：

1. AI 不可用时，核心内容、数据、自动化和交易能力继续运行。
2. 可靠动作应固化为 Flow 或有契约的 Skill，不让模型重复发明。
3. 策略可以组合，执行不能绕过权限、同意、频控、预算和审批。
4. 高风险动作始终保留人工闸门；自治只能按工作流逐步提升。
5. 每项行动有证据、版本、成本、结果和审计记录，并可暂停、接管和恢复。
6. 默认保持 PHP + JSON/SQLite 的轻量兼容性，仅按真实规模信号升级底座。

## 目标用户与边界

优先服务一人公司、创作者、个人品牌和没有专职增长团队的小型组织。他们既需要一套能直接运行的业务系统，也需要 AI 弥补经验和人力不足。

OpenFlow 不与专业 BI、重型 CRM、通用电商或大型企业套件竞争单点深度。存在价值是把足够完整的 TIPS 能力、确定性 Flow 和受控 Loop 放在同一套本地优先系统中，减少拼接、配置和人工搬运。

## 判断新建设的四把尺

每项新建设必须同时回答：

1. **业务价值**：是否解决真实 TIPS 问题，能否定义可衡量结果？
2. **范式归属**：它属于 Flow、Loop、二者共享底座，还是只是重复入口？
3. **可靠边界**：失败、超时、权限、预算、审计和回滚怎样处理？
4. **验证阶段**：现在是 Built、Integrated、Used 还是 Proven？

不能回答以上问题的功能，不进入主路线。

## 远景

OpenFlow 最终交付的不是更多页面或一次性 AI 对话，而是一套属于每个组织的增长工作流资产：

- 人的经验可以沉淀和稳定执行；
- Agent 可以在 TIPS 边界内补足经验、组合能力和小步试验；
- 真实结果能够回流并形成记忆；
- 有效策略可以被固化、复用、分享和持续改进；
- 用户始终能够理解、接管和控制系统。

**最终目标不是让 AI 取代人，而是让增长经验可以稳定交付并持续复利。**
