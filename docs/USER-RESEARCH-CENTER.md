# 用户研究中心能力规划 — 问卷/NPS 演进方向

> 版本：2026-09-08 规划
> 现状：survey-lib.php（问卷回收+4种题型+NPS）、nps-lib.php（NPS项目+评分）
> 目标：演进为"用户研究中心"，覆盖从"听见用户"到"理解用户"到"驱动决策"的完整链路

## 二、先进用户研究理论框架梳理

### 框架 1：Jobs-to-be-Done（JTBD）

**核心思想**：用户买产品不是为功能，是为了完成某个"任务"。

**关键方法**：
- **JTBD 访谈**：用户讲述"我是如何开始寻找这个产品的"故事
- **购买四力**：推力（现状不满）、拉力（新产品吸引）、惯性（不想变）、焦虑（新风险）
- **力量地图**：把用户决策过程可视化

**OpenFlow 接入点**：
- survey-lib.php 增加 JTBD 访谈模板题型（结构化故事引导）
- 用户画像增加 `jtbd_jobs[]` 字段（任务列表）
- 课程/产品页基于 JTJD 数据优化推荐

### 框架 2：Customer Journey Mapping（用户旅程图）

**核心思想**：把用户从认知到复购的全流程，标注每个触点的情绪/痛点/机会。

**关键要素**：阶段→触点→行为→情绪→痛点→机会

**OpenFlow 接入点**：
- 新增 journey-map 模块，绑定 CDP 事件自动填充阶段
- 每个触点关联 CDP 事件和问卷数据
- 旅程图可视化（admin/journey-map.php）

### 框架 3：Voice of Customer（VoC 客户之声）

**核心思想**：系统化收集、分析、响应所有用户反馈渠道。

**反馈源**：问卷/NPS + 社区帖子 + 客服对话 + 评论 + 社媒

**OpenFlow 接入点**：
- 汇总多渠道反馈到统一 dashboard
- AI 自动归类反馈（功能需求/bug/情感诉求）
- 反馈→需求→排期闭环

### 框架 4：Jobs-based Usability Testing

**核心思想**：不是测功能，是测用户能否用产品完成"任务"。

**关键指标**：任务成功率、任务耗时、错误率、SUS评分

**OpenFlow 接入点**：
- 任务测试模板（给用户发链接→记录操作→汇总结果）
- 与 CDP 的 session-replay 联动
- SUS 评分自动计算

### 框架 5：Continuous Discovery（持续发现）

**核心思想**：用户研究不是一次性项目，是持续的习惯。

**关键实践**：每周至少接触1个用户、机会评分矩阵、假设→验证→迭代

**OpenFlow 接入点**：
- "研究日历"：自动提醒"本周该做用户研究了"
- 机会评分矩阵（影响面×紧迫度×可行性）
- 假设管理：记录假设→关联验证结果→迭代

### 框架 6：Ethnographic Research（民族志研究）

**核心思想**：在用户自然环境中观察用户行为，而非问卷/访谈。

**方法**：日记研究、观察记录、场景描述

**OpenFlow 接入点**：
- 日记研究模板（用户每天记录使用场景）
- 观察记录表（结构化：场景/行为/情绪/洞察）
- 与 CDP 事件数据交叉验证

## 三、建议演进路径

### 第一批（P0）：基础能力补齐
1. **问卷增强**：矩阵题/滑块/排序/图片选择题型
2. **多维度满意度**：NPS + CSAT + CES 三联评分
3. **问卷模板库**：产品满意度/用户访谈/竞品分析 模板
4. **问卷结果 AI 分析**：AI 自动归类文本回答、提取关键洞察

### 第二批（P1）：深度研究能力
1. **用户旅程图**：可视化+CDP 事件自动填充
2. **JTBD 访谈模板**：结构化故事引导 + 力量地图
3. **用户画像深化**：心理属性+行为模式+决策风格
4. **竞品分析模块**：功能矩阵对比 + SWOT + 定位图

### 第三批（P2）：持续研究系统
1. **研究日历**：自动提醒+机会评分+假设管理
2. **VoC 统一仪表盘**：多渠道反馈汇总+AI 归类
3. **任务测试**：SUS 评分+任务成功率+CDP 联动
4. **研究知识库**：方法论模板+案例库+行业基准

## 四、当前架构下的技术可行性

| 能力 | 可行性 | 说明 |
|---|---|---|
| 问卷增强 | ✅ 高 | 题型枚举扩展，现有 survey-lib.php 可直接扩展 |
| NPS/CSAT/CES | ✅ 高 | nps-lib.php 已有计算逻辑，扩展评分维度 |
| 旅程图 | ✅ 中 | 需新增 admin 页面 + CDP 事件关联 |
| JTBD 模板 | ✅ 高 | 模板化问卷，survey-lib.php 扩展 |
| 竞品分析 | ✅ 中 | 新增 admin 页面 + 对比矩阵存储 |
| AI 洞察 | ✅ 高 | 已有 AI 能力，只需接上用户研究上下文 |
| 任务测试 | ⚠️ 中低 | 需要集成 session-replay + 自定义任务追踪 |

## 五、与 P1 ROADMAP 的关系

用户研究中心是 P1 的**辅助能力层**（D3 邮件自动化 + D4 AI 商业助手的延伸），
为闭环 A/B/C 提供数据支撑：
- A 闭环：用户满意度数据驱动产品定价
- B 闭环：分销商反馈驱动佣金政策优化
- C 闭环：买家评价驱动市场上架策略
