## 二、核心方法论：RBE 体系（M0-M8）

R.B.E Agent 系统设计营的九模块，是芭乐派增长方法论的完整骨架。

### M0 · 诊断（O.L.B 评分卡）
- **7 个维度**，每题 1-5 分：商业模式清晰度 / 转化引擎健康度 / 数据成熟度 / 触达能力 / 组织效率 / 内容资产 / Agent 就绪度
- 产出：增长瓶颈诊断报告（定位"你卡在哪"）+ Agent 杠杆收益排序

### M1 · Agent-Native 利润公式
```
利润 = 单位时间 × 客单价 × 客户规模 × (销转率 × Agent杠杆)
       − Agent固定成本 − Agent变动成本
```
- **核心洞察**：销转率是唯一的小数因子 → 利润的杠杆支点
- **Agent 化决策**：Agent 杠杆 > 1 且（固定+变动成本）< 被替代人力成本

### M2 · 四引擎模型 + 人的五个不可替代角色
四引擎同时驱动销转率：
1. **AI 增强转化引擎**：转化路径实时调整、A/B 自动收敛
2. **Agent 编排数据管道**：原始数据 → 可执行洞察的自动化链路
3. **自主个性触达网络**：正确时间/渠道/内容给正确用户
4. **模型驱动决策层**：Agent → 人，执行数据喂给决策层

人的五个不可替代角色（Agent 做不到的）：
- 系统设计 · 因果推断 · 设定边界 · 识别范式转移 · 价值判断

### M3 · Agent-Augmented DIKW 数据洞察
- 三层模型：**该看什么 → 看完做什么 → 建立可复用分析模型**
- 核心：从几百个指标捞出该看的 3-5 个，把洞察走到策略
- Agent 给假设，人做因果推断

### M4 · 转化引擎 Agent 化（直播+社群）
- 直播/社群不是目的，是人力约束下的一对多效率手段
- Agent 移除约束后重新设计：直播=短期快速筛选，社群=长期孵化

### M5 · 触达体系（Agent 自主触达）
- **触达 = 正确的时间 × 正确的渠道 × 正确的用户 × 正确的信息**
- 你不做触达，你设计触达规则，Agent 在边界内执行
- 三层次：触达强度 / 触达精度 / 触达温度

### M6 · 组织（管 Agent，管 prompt，管边界）
- 团队 = "你 + N 个 Agent"
- 管人核心：激励、沟通、协调；管 Agent 核心：设定边界、校准目标、升给判断

### M7 · Agent 系统设计 ★ 核心模块
- **增长漏斗 → Task Graph**：业务视角 → Agent 视角的翻译
- Task Graph = 有向无环图，每个节点是原子任务
- 三约束：**原子性 / 可观测 / 可中断**
- **五维判据（D1-D5）**判断任务可 Agent 化程度：
  - D1 规则明确度 · D2 结果可观测 · D3 错误成本 · D4 频次 · D5 数据可获得
  - 0-3 分：Agent 提案人确认 · 4-7 分：Agent 自主设异常信号 · 8-10 分：完全自主

### M8 · 增长模型白皮书
- 七大部分整合 M1-M7 产出：背景 / 利润公式 / 四引擎 / 数据模型 / 转化设计 / 触达矩阵 / Agent 系统
- 毕业产出 = 6 个月可执行的 Agent-Native 增长执行手册

## 五、质量与分发（写作铁律）

### 质量门禁（Anti-Slop）
- 每段回答 4 问：**谁会读 / 为什么现在读 / 读完改变什么 / 下一步是什么**
- BLOCK 条件：空泛词 ≥3（赋能/闭环/抓手/降维打击…）、内容缩水、FAQ<2、无 CTA、数据无源

### 分发矩阵（四档）
| 档位 | 平台 | 变体要求 |
|------|------|---------|
| 🟢 一级 | 公众号/知乎 | 直发 / 问答化改写 |
| 🟡 二级 | CSDN/掘金/思否 | 技术向精简 |
| 🟠 三级 | 简书/豆瓣/值得买 | 去营销感 / 评测向 |
| 🔴 四级 | 虎嗅/鸟哥笔记 | 完全重写投稿 |

### 运营铁律
- 修复优先于删除 · 先结论后数据 · 存量改造优先于新建 · 搬运内容隔离
