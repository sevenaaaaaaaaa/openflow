# OpenFlow XMP — 产品功能介绍

> AI 时代的网站增长、营销与运营操作系统。让个人网站与企业网站自己获得增长。

---

## 一、产品定位

OpenFlow XMP 不是建站工具。它是一套**增长操作系统**：把内容生产、AI 获取、线索培育和数据分析串成闭环，让网站从「被动的展示页」升级为「自动获客的增长引擎」。

**适用场景：**

- **个人品牌站 / 知识博主** — 内容自动发布 + GEO 收录 + 课程 / 咨询线上转化
- **企业官网** — 落地页获客 + CRM 管道 + 营销自动化培育
- **SaaS / 产品站** — SEO 全家桶 + 转化漏斗 + CDP 用户画像
- **内容 / 社区站** — UGC 评论点评 + 专题聚合 + IndexNow 收录
- **电商 / 品牌站** — 营销画布 + 复购自动化 + 多支付渠道

## 二、增长飞轮：六大引擎

$$
\text{内容} \rightarrow \text{获取} \rightarrow \text{承接} \rightarrow \text{转化} \rightarrow \text{洞察} \rightarrow \text{运营}
$$

## 六、全局特性

- **经营驾驶舱**：大屏 KPI 看板，三秒了解全局
- **运营主线（Flow）**：三条闭环（内容流/数据流/价值流）集成在一个操作面板
- **全局搜索（Cmd+K）**：跨模块全文搜索
- **通知中心**：所有业务事件统一提醒，未读角标
- **动态埋点**：`assets/inject.js` 自动注入全站追踪
- **Cli 命令行**：`php bin/of` 支持文章/会员/订单/舆情/定时任务
- **多语言**：可选多语言版本支持（zh-CN / en / ja）
- **形态驱动前台**：站点形态（内容中心/增长/商业/社区/开发）动态影响前台「为你推荐」

## 七、增长驱动引擎（主动推进）

OpenFlow 把舆情/AI/内容/CDP/MA 串成一条**自动推动网站前进的飞轮**：



- 每 6 小时 cron 自动推一轮
- AI 未配置时优雅降级（只做发现和建议）
- 配置 AI Key 后自动升级为真实生成（AI 草稿进待审核）
- 后台「增长驱动引擎」面板实时展示各环节状态

## 八、自我进化（自生长系统）

OpenFlow XMP 会随使用生长，每个人最终长成不同的形态。核心是一个三层闭环：

```
你使用 → 系统观察记录 → 长出形态 → 建议随之个性化 → 你采纳/忽略/转任务 → 系统继续调整 → 形态越来越像你
```

### 1. 自我进化引擎（SelfEvolve）

- **自动体检**：定期扫描 PHP 错误日志、前端 JS 错误、404 路由、空数据模块、页面性能
- **价值排序建议**：`价值分 = 严重度 × 个性权重 × 复发趋势 × 影响面`
- **关联诊断**：跨数据关联定位根因（如「课程空数据 → 详情页 404」症状链；「article.php 158 次错误」高频错误源定位）
- **建议转任务**：一键把建议转为 tasks 待办，融入团队协作
- **修复验证**：采纳后复扫对比信号，确认「已改善 / 未见改善」
- **建议过期**：超期未处理的非严重建议自动归档，严重问题永不自动归档

### 2. 生长引擎（GrowthEngine）

- **行为信号**：记录页面访问、建议采纳/忽略，形成「使用指纹」
- **形态画像**：总结站点长成什么样（📚内容中心型 / 🚀增长驱动型 / 💰商业转化型 / 💬社区运营型 / 🔧开发者友好型）
- **个性权重**：常用模块的建议自动提权，忽略的建议自动降权
- **进化时间线**：记录扫描/采纳/形态变化的完整生长轨迹
- **形态对比**：出厂均衡态 vs 当前形态的分布对比
- **周期报告**：自动生成「近 N 天概览」（采纳数/体检数/活跃时段）

### 3. 人机协同修复（SafeFix）

- **只生成方案**：扫描可确定性修复的 bug，生成补丁（原代码 vs 建议修改 diff 预览）
- **人工确认才应用**：系统绝不自动改代码，你点「审核通过」才执行
- **应用前自动备份**：原文件备份到 `data/safefix-backups/`
- **一键回滚**：应用后发现问题，从备份恢复

> 安全原则：人工确认是最后一道闸，系统永远不会自动执行修复。
