# 品牌声音规范（BRAND VOICE）

> 所有文案的唯一裁判顺序：**`GTM.md`「可以说/不能说」→ 本文 → 逐页替换表 `GTM-COPY.md`**。
> 页面改文案先改这里；新增说法先进「可以说」清单，核实不了不许上线。
> 适用范围：OpenFlow + 六个矩阵产品页 + 三套 demo + 首页。

---

## 一、声音三原则

1. **说他处境，不说我们功能。**
   ✅「市面上的增长工具都默认你有一支团队」　❌「一体化 All-in-one 平台」
2. **可验证 > 最高级。**
   可写：具体数字（116 API / 44 区块 / 128 契约测试）、可翻代码的机制（`SelfEvolve` / `McpGuard`）。
   禁用：「唯一」「首个」「最强」「提升 X%」「自动帮你修」。
3. **每句都要能补完"点了之后我会……"。**
   ❌「了解更多」是最差 CTA；每个按钮都要预告下一步。

## 三、CTA 词表（严格照用）

| 场景 | 用这个 | 不要用 |
|---|---|---|
| 主 CTA（开发者/自部署） | `在 GitHub 上开始` | 「立即体验」「马上开启」 |
| 免费开始（首页/课程） | `免费开始（开源）` | 「立即注册」 |
| 看产品/演示 | `先看它一天干什么` · `看产品矩阵` | 「了解更多」「查看详情」 |
| 托管版 | `开始免费试用` | 「立即购买」 |
| 企业/组织 | `申请方案` | 「联系销售」 |
| 内容页 | `订阅更新` | 「了解更多」 |
| 转化页 | `提交预约 →` | 「提交」「发送」 |

> 规则：同一页面**只允许一个主 CTA**（primary 样式），其余一律 ghost/文字链。
> 落地口径：**首屏的主 CTA 保持 primary**；页内其他 CTA 一律 `btn ghost`（含收口，用同一句词），
> 交互控件（如「运行一轮」）用 `btn subtle` 或文字链。同词同动作重复出现不算第二个主 CTA，
> 但样式不重复。例外：**定价/套餐卡内的 CTA 按档位区分**（付费档 primary、免费档 ghost），不计入本规则。审计：`php scripts/storyline-audit.php` 的 `MULTI_CTA` 项必须为 0。

## 四、矩阵衔接固定话术（六页 + 三 demo 通用）

每页底部矩阵块与正文提及其他产品时，只用这三种句式：

1. **互补**：「<本产品> 负责 X，<对方> 负责 Y，两者 API 互通——不是二选一。」
2. **零依赖**：「不要求你先装任何东西；想升级时，数据可平滑并入。」
3. **组合**：「常见组合：<A> + <B> + <C>（场景）。」

禁止：把对方写成「我们的模块」；写「必须先装 X」；比较优劣（矩阵内不内耗）。

## 六、禁用词与替换（与 GTM 第二节一致）

| 禁用 | 替换 |
|---|---|
| 唯一 / 首个 / 最强 / 行业领先 | 具体且可核验的差异（"它会自己体检，列出该修的"） |
| 自动帮你修 | 自动体检、给出改进清单（`SelfEvolve` 只产出建议） |
| 每 6 小时自动爬取 | 按你设的周期自动运行 |
| 提升 X% / 增长 Y 倍 | 没有真实客户数据前，一个数都不编 |
| 400+ 连接器 / 钉钉 / Slack / Salesforce | 真实清单（飞书/企微/WhatsApp/Notion/GitHub/SMTP/虎皮椒/GSC）+「Webhook/OpenAPI/MCP 自定义接入」 |
| Platform Intelligence / 自生长 AI Engine | 删除（代码里没有） |
| 跑流程（对用户说） | 替你跑 → "你只做判断，不做事" |
