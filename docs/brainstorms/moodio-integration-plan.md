## 一、Moodio 口径卡（写作时的唯一事实来源）

**一句话定位**：全球首个 AI 原生影视片场——创作者、团队与 AI Agent 从灵感一路协作到成片（剧本、参考、资产、剪辑、协作，端到端）。

**产品信息**：官网 www.moodio.art ｜ 开始创作 app.moodio.art ｜ **已开放少量内测名额，去 app.moodio.art 申请内测码**。

**五大功能**：剧本创作（和 Agent 对话写本、自动故事梗概+人物小传、中式/好莱坞双格式、角色/场景/道具分色标注、稿纸堆版本）｜ 参考搜索（自研影像检索引擎，按情绪/氛围/构图/景别/运镜搜，文字/图片/视频/手绘都能搜，一键反推提示词，毫秒级，免费）｜ 资产管理（模卡：一个角色所有变体收进一张卡、独立画布、上下文自动继承、pending/approved 审批）｜ 视频剪辑（Agent 自动推进或逐镜确认、时间线、免登录分享链接、秒级定位评论、导出 Final Cut 工程）｜ 团队协作（最高 15 人同画布毫秒级同步、角色分工并行、Figma 式画布评论、团队共享积分池、权限面板）。

**加分点**（按文章场景选用，不堆砌）：图片/视频工具箱只留最高频功能（重绘擦除/抠图/视角调整/一键截帧回画布）；3D 世界模型"走进画面换机位"，World Labs / Atlas 国内第一批接入；剧本导出 Word/PDF/FDX、剪辑导出 XML 衔接 Final Draft / 达芬奇；经 200+ 专业创作者 3000 分钟高强度测试。

**表达红线（官方五不 + 两禁，逐条遵守）**：
1. 不说 Moodio 成片效果优于其他平台——只说"帮你发挥自己的审美，协助而不代替"
2. 不比素材库数量——只说"审美好，能搜到你脑海中的画面"
3. 协同 ≠ 多人同时操作画布——是不同角色在不同画布、不同阶段共同推进
4. 专业工作流 ≠ 只服务专业团队——源自好莱坞方法，初学者也能用
5. 不宣称最终成片全在 Moodio 完成——各阶段可导出专业格式交专业软件
6. 禁用"一键成片""做 AI 就能赚钱"类卖点
7. 禁营销腔/硬推销；要情感共鸣、个性化审美表达

## 二、现有文章画像（植入必须服从的"当地法律"）

**人设（Gana）**：八年营销经验的超级个体——没有团队，一个人接项目、出方案、出图、剪片、发稿；AI 工具重度用户；对排版配色有强迫症；算账思维（ROI、时间成本、翻车账本）；反假榜单。

**文章自带的软文纪律（原文"专栏附记"）**：
1. 每个工具**先写坑再写赞**，顺序反了就像推销
2. 数字能核就核，标注来源（实测/声称/未测）
3. **植入只出现在「高效用法」或流水线某一步，开篇不出现品牌喊麦**
4. 不写自己没付费/没用过的东西的"体验"

**三类结构模板**：
- **选型/横评文**：立场 → 席位逐个（解决什么/体验/坑/💡）→ 排行表 → 我真实的一周用法
- **单品深测评**：这是什么 → 适合谁/不适合谁 → 安装 → 核心用法 → 注意事项与风险 → 与你现有工具的关系 → FAQ → 相关链接
- **清单/方法论文**：自报家门 → 逐工具（帮我干的活/真实体验和数字/踩过的坑/💡）→ ASCII 流程图 → 配图占位 → 总结

> 现有文章还有"配图：界面截图待发平台时上传"的占位文本——Moodio 段落配图可以直接填进这类占位，也可以新加。

## 三、融合总策略：四种植入模式

| 模式 | 用在哪 | 长什么样 | 改动深度 |
|---|---|---|---|
| **① 一致性回应式** | 讲角色漂移/一致性/系列脸的文章 | 在"一致性怎么做"处接一句：这类痛点已有产品化答案——Moodio 把角色/场景/道具做成模卡资产，剧本读一遍，后续生成自动继承设定 | 中（改写 1-2 段 + 补 80-150 字） |
| **② 选型席位式** | 工具选型/横评/清单文 | 给 Moodio 留一个"席位"：先写它适合谁不适合谁（含坑：内测期、影视向、平面设计不覆盖），再写它接哪段工作 | 中（新增一节 150-250 字，进排行表一行） |
| **③ 工作流环节式** | 工作流/自动化/内容产线文 | 在"视频产线/创意流水线"的对应环节引入：灵感检索→分镜→生成→审片，Moodio 把这几步收进同一个片场 | 中（在对应步骤补 80-120 字） |
| **④ 延伸阅读式** | 弱相关文章 | 正文一字不动，文末加"相关阅读"内链 1-2 条（指向强相关文章或 Moodio 主题新文） | 极小（只加链接块） |

**通用规矩**：
- 每篇 Moodio 内容 = **具像场景**（一个人/一个具体交付物）+ **一个卖点**（不堆砌）+ **一句坑或边界**（守人设纪律）+ 可选内链
- CTA 分级：强相关文末尾可带"内测申请"链接（app.moodio.art）；中相关只提产品与官网；弱相关只做站内内链
- 全部遵守官方七条红线；不出现"一键成片""AI 赚钱"字样
- 站内链接一律 `/article/{slug}` canonical 形态（现全站内链仅 1 篇有，此轮顺带补内链网）

## 五、写作规范（批量脚本的硬约束）

1. **语气对齐样本**（从现有文章提炼）："我踩过的坑是……" "它能接住哪一段工作" "别把 X 当 Y" "能不能交差" ——先坑后赞，句子有人称
2. 每段 Moodio 内容必须包含**至少一个具体细节**（模卡/秒级定位评论/手绘搜图/FDX 导出这类实指），拒绝"强大/领先/革命性"空词（对齐站内 Anti-Slop 门禁）
3. h2/h3 会被自动加锚点生成 TOC——新加标题不手写 id
4. 不动 `status/created_at/slug/author`；更新 `updated_at`（内容确实变了，sitemap lastmod 诚实反映）；`seo_desc` 不强制改
5. 内测口径必须带"少量内测名额"，不说"注册即用/免费使用"（除参考搜索明确标"免费"）
6. 外链 app.moodio.art / www.moodio.art 直接 http 外链（与现有 lovart 链接同待遇）
7. 每次批量：先 tar 备份 data/articles/ → 内存修改一次写回 → `json_decode` 校验 → 跑契约测试 → `scripts/deploy.py --with-data data/articles/index.json` 推服务器 → `chown www:www` 确认

## 七、执行流程（拍板后）

1. 写批量脚本：逐篇按层级选择模式 → 生成注入草案（内存）→ 输出每篇 diff 预览文件
2. 我抽样 15 篇人工校对语气/事实/红线 → 你可抽查
3. 全量应用：tar 备份 → 一次写回 → JSON 校验 → `php tests/contract_suite.php` + PHPUnit
4. 图片处理：可用资产转 WebP → `deploy/sync-r2.py` 上 R2（新文件名防 7 天 immutable 缓存坑）
5. 发布：`scripts/deploy.py --with-data data/articles/index.json` → 服务器 `chown www:www` + 清缓存
6. 线上冒烟：抽 5 篇看渲染/图片/内链；`sitemap.php` 条数不变性检查
7. 入档：docs/handbook/CHANGELOG.md 补一段（产品四件套纪律）
