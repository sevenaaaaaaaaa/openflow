# ADR-005：高意向线索黄金 Loop 沙盘

状态：已实施（确定性沙盘）

## 决策

第一个黄金 Loop 固定为“高意向线索 → 成交”，但第一步只建设隔离沙盘。数据必须明确声明为 `synthetic`，对象 ID 使用 `SYNTH-` 前缀；生产标记的数据会被拒绝。

沙盘按照 TIPS 组织：Touch 汇总触点，Insight 使用公开权重和逐项证据计算意向，Personalize 在同意与抑制规则内准备标签，Sell 只给出待审核跟进建议。它不调用生产 Action Gateway 执行接口，不触达客户，不生成真实报价或成交记录。

## 验收指标

- precision 与 recall；
- 错误触达率；
- 模拟转化率；
- 同意缺失与抑制对象拦截率；
- 每一个分数和行动能否追溯至信号。

这些指标是沙盘算法验收结果，不得合并进真实业务报表。真实数据陪跑和人工审批是后续独立切片。
