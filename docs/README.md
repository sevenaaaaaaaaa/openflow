# OpenFlow 文档导读

这个目录有两层文档：**战略层**回答「我们为什么存在、往哪走」，
**工程层**回答「现在是什么状态、怎么建、怎么发」。当前共同主线是：

> **OpenFlow 是一套基于 TIPS、同时支持 Flow 与 Loop 的开源增长操作系统。**
> Flow 由人设计、Copilot 辅助并确定性执行；Loop 由人定义目标与边界，TIPS Agent
> 调用 Skills、Harness 和成熟 Flow，在受控循环中执行、评估和调整。两者长期并存，
> 共享同一套业务数据、权限、审计与执行能力。

先读 `VISION.md`（北极星，5 分钟），它给全部规划一个共同坐标系；再按需要
往下走。

## 战略层 · 产品北极星与竞品审计

`VISION.md` 立坐标系，七份审计在这个坐标系下逐模块做深度竞品对标——每份都
**判断"好不好"（不只是"有没有"）**，分清「守（地基）」与「攻（创新）」，
并把该模块的定位写回根目录 `README.md`。

| 文档 | 回答什么问题 | 一句话结论 |
|---|---|---|
| `VISION.md` | 长期不变的产品边界 | TIPS 是共同业务模型；Flow/Copilot 与 Loop/Agent 是两种并存范式；业务、稳定与兼容优先 |
| `FLOW-LOOP-ROADMAP.md` | 新方向如何渐进落地 | 先基线与共享契约，再建受控运行时和一个黄金 Loop，验证后才做双工作台与规模化 |
| `FLOW-BASELINE.md` | 现有 AITIPS Flow 如何测量 | 8 个运行维度形成可重复 JSON 基线，完整 77 个契约测试阻断回归 |
| `ADR-001-SHARED-DOMAIN-CONTRACTS.md` | Flow 与 Loop 是否共用业务对象 | 共用身份、权限、审计和执行入口；Loop 不复制现有业务实现 |
| `AUDIT-01-CONTENT.md` | 内容/CMS 够不够，AI 让内容变成什么 | 内容不是页面，是活的知识与销售系统；生产三范式（人把关到什么程度） |
| `AUDIT-02-CDP.md` | 用户数据/CDP 好不好，怎么不重造 BI | profiles.json 是 P0 架构债；价值在「画像即 Agent 实时决策供给」，不在报表 |
| `AUDIT-03-MA.md` | 营销自动化是不是核心 | **自动化不是核心，个性化才是**；从「人连流程图」到「Agent 逐人决策」 |
| `AUDIT-04-SALES.md` | CRM 痕迹怎么破 | 别做更好用的记录本；让成交**反哺** CDP/MA/Content + Agent 当销售经理 |
| `AUDIT-05-COMMERCE.md` | 电商这块最大的坑在哪 | 电商两张脸；双边平台是坑；把增长引擎**多租户化**，给每个创作者一支 AI 增长团队 |
| `AUDIT-06-ECOSYSTEM.md` | 开发者/创作者生态怎么建 | **OIA（One is All）**：一次参与同时是开发者/创作者/作者，全平台赋能 |
| `AUDIT-07-SYNTHESIS.md` | 六块缝上了没有、整体还缺什么 | 有躯体、有传入神经，**但没有大脑**；下一件最重要的事是补「中枢神经 + 大脑」 |
| `AUDIT-08-EVOLUTION-REVIEW.md` | 演进路线（`EVOLUTION.md`）好不好、该不该照做 | 瓶颈**不是"访问散落"、是"整批读写"**：事件早已在 SQLite 上，单条埋点仍要 134ms/26MB——抽象层不治此病。**结论的可读版见 `ROADMAP.md`** |

七份模块审计和跨模块总合仍是重要的事实与设计依据；其中“增长大脑”的结论已经
进一步收敛为 Flow/Loop 路线。审计文档保留当时判断，不把其中规划项当作当前承诺。

## 变更日志 · 2026-08-30（这一天改动很大）

这一天从「质检收口」推进到「完整产品叙事」，可分四批：

**① 质量与安全收口**（结构性，非补丁）
- 全面 QA 质检，修复合并/退款遗留 + 三个空库致命 bug；
- CSRF 在 `require_login` 统一入口**结构性收口**（不再逐页打补丁）+ 目录穿越修复；
- 敏感操作在统一入口**自动留痕**（audit log，参数脱敏）；
- 管理员**两步验证（TOTP 2FA）** + **自定义角色与细粒度权限矩阵**（admin 永远全权，防自锁）；
- 补齐四项未做任务 A3/C2/C3/D1（CDP 分群→CRM 批量建线索、PluginSDK、三个示例插件、events 索引优化）。

**② Sales 打通「线索→报价→收款→成交→交付」**
- 线索未跟进**自动提醒**；
- **收款链接/报价单**：线索→报价→在线付→自动推进管道为已成交；
- 收款单挂**交付阶段 + 待办**：一人盯住「钱到活没完 / 该催尾款」。

**③ 生态地基**
- **作者管理**：把散落的署名收成一等身份（实体化，为生态铺路）；
- **统一站内营销投放**：收编散落的通知条/弹窗/内嵌，加真定向。

**④ 产品北极星 + 七份深度竞品审计**（本目录战略层）
- 立 `VISION.md` 北极星；
- `AUDIT-01…07` 逐模块深度对标 + 创新层；每份定位写回根 `README.md`（六观）；
- `AUDIT-07` 跨模块总合：**六器官 → 一个生命体**，点出「缺的是中枢神经 + 大脑」。
