# OpenFlow 使用指南

> 核心定位 · Features · 具体用例。写给"刚开始用 OpenFlow 的一人公司/小团队",
> 也是官网改版的素材源(与本 README 同源维护)。

---

## 核心定位

**OpenFlow 是 TIPS 理念的 all-in-one 增长平台,降低一人公司与中小团队数字化+AI 化的启动门槛——把属于未来的数字能力兑换到现在。**

它不是要取代你已经会用的所有工具,而是回答一个更基础的问题:一个人的公司,怎么拥有一支团队才有的增长能力?

- **Touch(触达)**:让对的人发现你——CMS、落地页、SEO/GEO、多语言、全平台分发;
- **Insight(洞察)**:看清谁来了、做了什么、为什么转化——CDP、分群、漏斗、归因;
- **Personalize(个性化)**:对不同的人在对的时机做对的动作——画布、动态内容、频控;
- **Sell(销售)**:把意向变成收入并让真相回流——CRM、商城、订阅、课程、佣金。

四力之间不是四个功能区,是一条反馈回路:成交与丢单的真相回流洞察,洞察调整内容与渠道。
**AI 贯穿全链但永不越权**——发布、群发、价格、支付,永远有人工闸门。

## Features(按你将真实用到的顺序)

### 1. 今日主线 —— 每天的第一屏
全站信号收成一条行动脊柱:立即(钱/风险/时效)· 今日(目标推进)· 本周(策略判断)。
每件事带"为什么现在做"和一键下一步;完成回流,主线越来越懂你。

### 2. 每日晨会 —— 3 分钟被汇报
小福(你的增长 COO)每天把 KPI、重点、待拍板决策讲成 3 分钟口播(浏览器语音朗读),
文字版随时可看。像合伙人,不像仪表盘。

### 3. AI 岗位 —— 有 KPI 的数字员工
"内容编辑"岗位每天看热点 → 转选题 → 写草稿(带内容健康分)→ 向主线交班;
草稿永远待审;连续两周不达标自动降级"仅建议"。未来会有更多岗位(SEO 专员、私域运营)。

### 4. 一句话指挥 & Agent 运行时
输入"给 7 天没来的会员发一封召回邮件",小福拆成可执行计划,你逐步确认;
Agent 运行时则让 AI 在白名单工具里链式执行,安全动作自动做,中高风险等你批准。

### 5. CDP 用户画像
匿名访客与会员身份自动合并,一人一册:来源、浏览、表单、订单、学习记录一条时间线。

### 6. 营销自动化画布
SVG 真流程图:拖触发器、条件、动作与延时;A/B 分流、灰度、人工确认节点;执行全程留痕。

### 7. 内容引擎 + SEO/GEO 全栈
文章/页面/资料/播客一站管理;内容健康分逐项打分、内链引擎一键补链;
四大搜索引擎站点工具接入;热点雷达(HN/GitHub/RSS)每天聚类出可写选题。

### 8. 商业变现
商城、购物车、优惠券、订阅计费、课程交付、推荐分销、自动收据;
虎皮椒/微信/支付宝/Stripe 多渠道,收据与退款流程自动化。

### 9. 生态与开放
插件平台 v2(钩子/API 路由/后台菜单/定时任务)、MCP Server(外部 AI 直连站点)、
CLI(`bin/of`)、PWA 四端、API 权限矩阵(109 端点四档)。

## 具体用例(可直接照抄的实战路径)

### 用例 A · 内容获客闭环(创作者/咨询顾问)
1. 配置热点雷达关键词 → AI 岗位每天产出 3 篇选题草稿;
2. 早餐时听晨会 → 审核 1-2 篇草稿(改开头结尾,10 分钟)→ 发布;
3. 发布自动触发 IndexNow 收录推送 + 内链引擎挂相关文章;
4. 落地页绑定转化目标 → 访客留资自动进 CRM 并打分;
5. 高分线索 48 小时未跟进,自动化画布自动提醒你。
**结果**:内容产能从"每周憋 1 篇"到"每天有得审",跟进不再漏。

### 用例 B · 私域复购(独立电商/知识付费)
1. CDP 分群"加购未付 24h"→ 画布自动发召回邮件(含券);
2. "购买课程 7 天后"自动推送进阶课页 + 学员案例;
3. 订阅到期前 7 天自动提醒 + 老客专属续费券;
4. 推荐码体系让老客分享赚钱,佣金自动结算。
**结果**:复购不再靠"想起来了发一下"。

### 用例 C · 一人服务公司(设计/财税/律所)
1. 官网(CMS+落地页)+ 预约表单 + 自动建线索一条龙;
2. 客户进入 CRM 管道:新线索→已报价→交付中→已成交,每阶段自动化提醒;
3. 对话式 BI 每周问一句"这个月线索从哪来",决定下个月内容方向;
4. 数据全在自己服务器,满足行业合规。
**结果**:获客-跟进-交付-复盘一个人转得动。

### 用例 D · 课程/训练营(LearnFlow 前置场景)
1. 课程上架 → 免费试看 → 付费解锁(先在 OpenFlow 内完成);
2. 完课自动颁发证书(可验证链接),学员晒图带来新报名;
3. 学习进度分析:哪节课流失最多,下周改哪节;
4. 学员规模化后,进阶到 LearnFlow 单件(交付更重、运营更深)。

## 与矩阵的关系

OpenFlow 是入口层。当你长出更深的单点需求:
- 内容产能要规模化 → **MFlow**
- 要全域数据打通(不限于本站)→ **UserLoop**
- 要外部情报(趋势/竞品/舆情)→ **inFlow**
- 变现链路要独立复用 → **PayFlow**
- 课程交付要重运营 → **LearnFlow**
- 投放落地页要批量 → **WebsFlow**

## 诚实的边界

- AI 产出全部是草稿/建议,关键动作永远人工确认;
- 黄金 Loop(线索→成交的自动闭环)在真实数据上仍在验证;
- 直播媒体层需要外部流媒体服务;短信为演示模式;
- AI 依赖你配置的模型与预算,未配置时系统照常运行(功能明确降级)。
