## v1.4.0（2026-08-20 · 当前版本）

### 主题：全域智能增长操作系统

从 1.3「功能齐全」进阶到「数据可信、触达闭环、体验可测、Agent 可指挥」：**一个 AI 底座 + 四大能力域**。

### Agent 底座
- **小福增长 Copilot**：自然语言 → 直接创建自动化流程（欢迎邮件 / 购买发券 / 线索跟进 / 完课奖励 / 会员升级）；快速数据问答（线索 / 收入 / 活跃 / 转化率）
- **转化漏斗级 AI 巡检**：落地页 / 渠道 7 天转化率环比骤降自动检测 + 根因建议 + 告警（cron 每 6 小时）
- **AI 一键生成落地页**：需求描述 → AI 生成结构化区块 → 落地页 → 编辑
- **MCP Server 安全加固**：HTTP 模式 API Key 鉴权（`Authorization: Bearer <key>`）

### 数据可信底座
- **Tracking Plan**：事件 Schema 校验（必填属性 / 身份字段）+ 上报质量监控面板
- 实时分群（事件落地即时评估 + 进出群触发）· 用户旅程行为时间线
- **小程序 openid → CDP 桥接**（身份图谱合并 + `mini_program_login` 事件）
- **数据仓库出向导出**：Token 鉴权 + events / orders / members 等表 JSON / CSV 导出

### 触达闭环
- **邮件营销完整闭环**：退订链接 / 端点（HMAC 签名）· 打开（pixel）与点击统计 · 邮件模板编辑器 · 群发自动接入
- **跨渠道频控 + 疲劳度**：每日 / 每周各渠道触达上限，自动化流程自动遵守

### 体验可测 + 合规
- **点击热力图**：前端坐标采集 + 后台 iframe 热区渲染
- **会话回放**：按会话重放点击轨迹动画
- **弹窗 A/B 变体**：50/50 分流 + `fcTrackAB` 转化上报
- **隐私中心**：用户数据导出 / 账号注销（清 PII）/ 邮箱手机脱敏
- **报表邮件订阅**：每日 / 每周经营报表自动推送
- 视频号 / 抖音发布平台扩展

## v1.3.0（2026-08-19 · 上一版本）

### 主题：商业闭环 + 增长引擎重构

系统性的架构修复与引擎补全，确保**数据全链路流动、零卡点**。

### 商业闭环（P0）
- **订单三源统一**：SQLite 主 + JSON 兜底去重，修复「付款不解锁课程 / 个人中心订单错位 / 分销统计读错源」
- **作者分成入账修复**：`submitted_by` 真实 id 贯通 + 旧数据自愈，修复被注释吞掉的交付函数
- **课程三层分成**：平台抽 10% + 作者分成 + 分销佣金，支付后自动入账
- **开发者 / 讲师发布课程**：章节 + 课时 + 定价 + 后台审核（通过 / 拒绝）
- **课程 ↔ 生态交叉销售**：课程页推生态工具、商品页推配套课程

### 增长引擎核心（P1）
- **入站数据接收层**：外部 Webhook 推送 → 签名校验 → CRM / CDP 事件 / 画像
- **外部数据连接器**：REST API / CSV 主动拉取 → CDP / CRM，cron 定时同步
- **WebhookSystem 接线**：8 类业务事件真实出站
- **自动化完善**：补齐 5 个死触发器埋点 · 站内动作（打标签 / 积分 / 发券 / 站内信）· 条件分支真并行 · segment 进出群触发
- **个性化闭环**：分群 → 专属内容展示 · 商品 / 课程个性化推荐
- **CDP 深度**：修复留存取数 bug · 补 engagement 评分 · 事件明细筛选 / 导出 · 分群成员 / 导出 · 双分群路径统一 · CAPI 扩展（Lead / Subscribe / fbp / fbc）

### 活动 · 导航 · 实验 · 多语言（P2）
- **活动系统升级**：线上 / 线下 + 容量 + 直播间 / 回放 · 原生报名（名额 / 审核）· 开始前提醒 · 前端活动列表页
- **OpenFlow 导航站**：AI 时代工具集种子数据（开源 / 流程 / Agent 等 6 分类）
- **实验平台**：Z 检验显著性 + p 值 + 置信区间 + 最小样本量
- **多语言 i18n**：URL 前缀 / cookie 检测 · 翻译包 · 切换器 · hreflang

### 广告 · 知识平台 · 融合（P3）
- **投放管理**：计划 / 素材（DAM）/ 指标 / CPC / CPA / ROI，CAPI 转化对账
- **知识平台双向同步**：文章发布 → Notion / 外部 Webhook（HMAC）
- **融合方案**：公开内容 API（SSR）· SSO 统一登录 · `/growth/` 子路径挂载

## v1.2.0（2026-08-17 · 生态与商业化）

### 主题：生态与商业化（Open Eco）

把 OpenFlow 从「自用增长系统」升级为「可运营的生态商业平台」，打通开发者共创、商品交易、分销分佣、会员订阅与 ToB 企业服务。

**经营驾驶舱**：KPI 环比 + 收入目标进度 · 活跃分析（DAU/WAU/MAU）· 行为路径 · 偏好洞察

**来源归因（UTM 全维度）**：前端采集 UTM 五参 + 广告点击 ID · SEO/SEM/信息流/社媒分类 · Referrer 兜底

**CRM 全生命周期**：线索 ↔ CDP 画像打通 · 商机（金额/赢率）· 客户（合同/ARR）· CSV 导入

**内容日历**：月/周视图 · 多平台发布计划

**生态市场**：33 个官方 Skills + 11 个主题（5 行业）· 开发者入驻审核全流程 · 商品组合包（嵌套递归交付）

**商业化**：一级分销（平台 10% + 分销者 + 作者）· 商品会员（年度/永久，每日额度）· ToB 商业发行版（企业实体 + 申请 → 控制台）

**数据迁移助手**：6 类数据 CSV/JSON/XLSX 导入 · 字段映射 + AI 体检

**核心修复**：JSON 会员与 Database 表双轨不同步（导致注册后解锁/余额失效的 bug）· 订单/成员表补列 · 分销佣金单位统一

## v1.1.0（2026-08-14 · 自我进化）

### 主题：自生长能力

把 OpenFlow 从「工具」升级为「会生长的系统」：`使用 → 观察记录 → 长出形态 → 建议个性化 → 采纳/忽略 → 继续调整`。

- **自我进化引擎（SelfEvolve）**：自动体检（PHP/JS 错误 / 404 / 空模块 / 性能）· 前端遥测 · 后台进化中心 · cron 每 6 小时
- **生长引擎（GrowthEngine）**：行为信号采集 · 形态画像（内容/增长/商业/社区/开发者）· 个性权重
- **人机协同修复（SafeFix）**：生成补丁 → 人工确认 → 可回滚（绝不自动改代码）
- **增长驱动引擎**：爬取热点 → AI 洞察 → AI 撰写 → 内容更新 → SEO → 转化 → 触达 → 洞察 → 报告，每 6 小时一轮
