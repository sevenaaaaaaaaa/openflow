## v1.2.0（2026-08-17 · 当前版本）

### 主题：生态与商业化（Open Eco）

本轮把 OpenFlow XMP 从「自用增长系统」升级为「可运营的生态商业平台」，打通开发者共创、商品交易、分销分佣、会员订阅与 ToB 企业服务三大闭环。

### 一、增长数据层（三大核心模块升级）

**经营驾驶舱**
- KPI 环比对比（本期 vs 上期涨跌箭头）+ 收入目标进度条
- 活跃分析：DAU / WAU / MAU + 时段热力 + 新老访客占比
- 行为路径：Top 落地页 / 来源 / 转化汇总
- 偏好洞察：设备 / 语言 / 内容分类偏好

**来源归因（UTM 全维度）**
- 前端采集 UTM 五参数 + 广告点击 ID（gclid/fbclid/msclkid/bd_vid）
- 归因分类：SEO / SEM / 信息流 / 社媒 / 邮件 / 自定义 / 直接，Referrer 兜底识别
- 支持任意自定义平台（与 UTM 工具同逻辑）

**CRM 全生命周期**
- 线索 ↔ CDP 画像打通（详情显示设备/来源/标签）
- 商机管理：金额 / 预计成交 / 赢率
- 客户管理：won 转客户（合同 / 续费 / 健康度 / ARR）
- ARR 报表：ARR 构成、商机管道、流失率
- CSV 批量导入线索

**内容日历**
- 月 / 周视图切换
- 分发渠道发布计划（定时发布队列 + 已发布记录，多平台标记）

### 二、生态市场（Open Eco）

**官方产品上架**
- 33 个官方 Skills（SEO/社媒/文案/分析/工具/工作流）+ 11 个主题
- 主题覆盖 5 行业：新零售 / 电商 / 传媒 / 游戏 / 实体产业（基于行业标杆网站调研）

**开发者全流程**
- 入驻申请（审核）→ 开发套件 → 提交产品 → 后台审核 → 上架
- 开发者中心（个人中心内）：我的产品 / 提交 / 组合包创建
- 后台开发者审核 + 产品审核（通过/拒绝）

**商品组合包**
- Skills 包 / 主题包 / 功能组合 / 混合大组合（嵌套组合包）
- 递归交付解锁全部内容

### 三、商业化（分销 + 会员 + ToB）

**一级分销体系**
- 每个开发者产品可配分销（平台抽 10% 覆盖支付手续费 + 分销者比例 + 作者剩余）
- 一级分销（不设二三级），分销码 + 推广链接 + 分销中心看板（佣金/订单/余额/明细）

**商品会员机制**
- 年度会员 ¥299/365天，每天免费下单 5 个任意商品
- 永久会员 ¥599/不限时，每天下载 10 个任意商品
- 每日额度按自然日重置；商品仅限本人账号使用（禁止二次开发/打包/魔改）

**ToB 商业发行版**
- 企业实体（org）+ 状态机（意向→有效→报价→签约→部署→使用）+ 多成员
- 官网「商业发行版」申请页：游客可填，自动创建 C 端账号 + 邮件设密关联 C/B
- 后台企业客户管理 + 前台企业控制台（现有系统之下，不新增后台）

### 四、数据迁移助手
- 6 类数据导入：文章 / 页面 / 线索 / 用户 / 评论 / 订单
- 格式：CSV / JSON / XLSX（自研轻量解析）
- 字段映射 + 预览 + 冲突处理 + 完成报告
- 导入模板下载（各类型完整字段）
- AI 体检：字段识别 / 质量诊断 / 映射建议 / 导入指南

### 五、隐私与体验
- 全站化名 Seven，去除可定位身份的原始经历
- 首页主 CTA 修复、开源死链修复、个人中心真实数据、表单防重复、移动端横向溢出修复

### 六、修复
- 修复 JSON 会员与 Database members 表「双轨不同步」——导致注册后解锁/余额/会员额度/佣金全部失效的核心 bug
- orders 表补分销列（distributor_rate/platform_fee）、members 表补会员列
- 分销佣金单位统一（百分数）
- 收入报表合并课程 + 数字商品订单，区分会员免费单

## v1.1.0（2026-08-14 · 上一版本）

### 自我进化系统（自生长能力）

本轮将 OpenFlow XMP 从「工具」升级为「会生长的系统」。核心是三层闭环：
`使用 → 观察记录 → 长出形态 → 建议个性化 → 采纳/忽略 → 继续调整 → 形态越来越像你`。

**第一轮：自我进化引擎（SelfEvolve）**
- 自动体检：扫描 PHP 错误日志 / 前端 JS 错误 / 404 路由 / 空数据模块 / 页面性能
- 前端遥测：`api/evolution-report.php` + site-shell 自动上报 JS 错误、页面性能
- 后台「自我进化中心」：建议清单 + 统计卡 + 平台健康度 + 迭代历史
- cron 每 6 小时自动体检，发现严重问题自动通知

**第二轮：生长引擎（GrowthEngine）**
- 行为信号采集：记录页面访问、建议采纳/忽略，形成「使用指纹」
- 形态画像：📚内容中心型 / 🚀增长驱动型 / 💰商业转化型 / 💬社区运营型 / 🔧开发者友好型
- 个性权重：常用模块建议提权，忽略建议降权
- 后台「你的平台形态」卡 + 采纳/忽略按钮

**第三轮：价值排序 + 关联诊断 + 人机协同 + 前台联动**
- 第一梯队：跨数据关联诊断（症状链 + 高频错误源定位）、价值排序升级、建议转任务、修复验证钩子、进化时间线
- 第二梯队：时段模式（活跃时段）、建议过期机制、形态对比、周报摘要
- 第三梯队：**人机协同修复（SafeFix）**——系统生成补丁、人工确认才应用、可回滚；形态驱动前台；个性化推荐（学院「为你推荐」区块）

### 增长驱动引擎

- 把舆情/AI/内容/CDP/MA 串成主动推动网站前进的飞轮：爬取热点 → AI 总结 → AI 撰写 → 内容更新 → SEO 优化 → 转化链路 → 激活触达 → 数据洞察 → 增长报告
- 每 6 小时 cron 自动推一轮，后台「增长驱动引擎」面板实时展示各环节状态
- AI 未配置时优雅降级（只做发现和建议），配置 AI Key 后自动升级为真实生成（草稿进待审核）

### 安全原则

协同修复绝不自动改代码，人工确认是最后一道闸；应用前自动备份，可一键回滚。

- **项目正式更名为 OpenFlow XMP** — AI 时代的网站增长、营销与运营操作系统
- 完整品牌替换：Flowcoming → OpenFlow，域名为 nownexts.com
- 中文品牌标识统一
- 产品定位从「组织幸福 CXM」升级为「网站增长 XMP」

### 定位升级
- **首页**：重写为「让网站成为自己的增长引擎」，围绕「内容 + AI + 自动化」三引擎
- **关于页**：创始人寄语、公司简介、使命愿景价值观、团队页面全部重写
- **产品页**：从「诊断→赋能→沉淀」三层幸福模型，升级为「内容→获取→转化」增长闭环

- **导航站**：从心理学网站导航，升级为增长/SEO/AI 工具导航

### 基础设施
- CLI：`bin/fc` → `bin/of`，内部函数与文档引用全部更新
- 数据库：`data/db/flowcoming.db` → `data/db/openflow.db`
- 后台品牌占位符、系统 Prompt、预设值全部更新

### 文档
