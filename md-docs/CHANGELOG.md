## v1.1.0（2026-08-14 · 当前版本）

### 自我进化系统（自生长能力）

本轮将 OpenFlow XMP 从「工具」升级为「会生长的系统」。核心是三层闭环：
`使用 → 观察记录 → 长出形态 → 建议个性化 → 采纳/忽略 → 继续调整 → 形态越来越像你`。

**第一轮：自我进化引擎（SelfEvolve）**
- 自动体检：扫描 PHP 错误日志 / 前端 JS 错误 / 404 路由 / 空数据模块 / 页面性能
- 前端遥测：`api/evolution-report.php` + site-shell 自动上报 JS 错误、页面性能
- 后台「自我进化中心」：建议清单 + 统计卡 + 平台健康度 + 迭代历史
- cron 每 6 小时自动体检，发现严重问题自动通知

**第二轮：生长引擎（GrowthEngine）**
- 行为信号采集：记录页面访问、建议采纳/忽略，形成「使用指纹」
- 形态画像：📚内容中心型 / 🚀增长驱动型 / 💰商业转化型 / 💬社区运营型 / 🔧开发者友好型
- 个性权重：常用模块建议提权，忽略建议降权
- 后台「你的平台形态」卡 + 采纳/忽略按钮

**第三轮：价值排序 + 关联诊断 + 人机协同 + 前台联动**
- 第一梯队：跨数据关联诊断（症状链 + 高频错误源定位）、价值排序升级、建议转任务、修复验证钩子、进化时间线
- 第二梯队：时段模式（活跃时段）、建议过期机制、形态对比、周报摘要
- 第三梯队：**人机协同修复（SafeFix）**——系统生成补丁、人工确认才应用、可回滚；形态驱动前台；个性化推荐（学院「为你推荐」区块）

### 增长驱动引擎

- 把舆情/AI/内容/CDP/MA 串成主动推动网站前进的飞轮：爬取热点 → AI 总结 → AI 撰写 → 内容更新 → SEO 优化 → 转化链路 → 激活触达 → 数据洞察 → 增长报告
- 每 6 小时 cron 自动推一轮，后台「增长驱动引擎」面板实时展示各环节状态
- AI 未配置时优雅降级（只做发现和建议），配置 AI Key 后自动升级为真实生成（草稿进待审核）

### 安全原则

协同修复绝不自动改代码，人工确认是最后一道闸；应用前自动备份，可一键回滚。

## v1.0.0（2026-08-10 · 上一版本）

### 品牌升级
- **项目正式更名为 OpenFlow XMP** — AI 时代的网站增长、营销与运营操作系统
- 完整品牌替换：Flowcoming → OpenFlow，域名为 nownexts.com
- 中文品牌标识统一
- 产品定位从「组织幸福 CXM」升级为「网站增长 XMP」

### 定位升级
- **首页**：重写为「让网站成为自己的增长引擎」，围绕「内容 + AI + 自动化」三引擎
- **关于页**：创始人寄语、公司简介、使命愿景价值观、团队页面全部重写
- **产品页**：从「诊断→赋能→沉淀」三层幸福模型，升级为「内容→获取→转化」增长闭环
- **解决方案页**：从四层课程体系，升级为四层增长方案（内容增长/线索转化/自动化培育/数据洞察）
- **社区页**：从组织幸福洞察，升级为网站增长洞察
- **导航站**：从心理学网站导航，升级为增长/SEO/AI 工具导航

### 基础设施
- CLI：`bin/fc` → `bin/of`，内部函数与文档引用全部更新
- 数据库：`data/db/flowcoming.db` → `data/db/openflow.db`
- 后台品牌占位符、系统 Prompt、预设值全部更新
- 分类/Tag/Skill/社区/点评等 taxonomy 数据刷新

### 文档
- 新增：FEATURES.md、USAGE.md、CHANGELOG.md、REQUIREMENTS.md、ROADMAP.md
- 更新：DEVELOPER.md、PRODUCT-PLAN.md 品牌名与定位

## v0.x（2021–2026-08  ·  历史版本）

### 平台核心能力建设（已完成）

**内容引擎（CMS）**
- 文章管理：CRUD + 分类 + 标签 + 专题 + 版本历史
- 批量导入：飞书/Notion/Obsidian 外部迁移
- 页面编辑器：可视化页面管理
- 落地页管理

**增长引擎（Growth）**
- SEO 全家桶：页面 SEO + 批量策略 + 结构化数据 + Sitemap + 301 重定向
- GEO：话题监控 + AI 自动成文 + IndexNow
- 舆情监测：全网采集 + 情感分析 + 趋势报告
- A/B 测试框架

**AI 引擎**
- AI Agent（小福）：多供应商 + 对话 + 快捷操作 + 知识库 RAG
- SkillSystem：AI 技能资产的发布/执行/打分
- SkillGenerator：一句话描述 → 自动生成 Skill
- MCP Server：stdio + HTTP 双传输，10 个内置工具

**转化引擎**
- 落地页与表单：可视化构建 + 门禁下载
- CRM 管道：线索评分 + 去重合并 + 跟进阶段
- 营销自动化：画布编排 + 多渠道触达（邮件/短信/企微）
- Campaign 管理：多期次营销活动

**数据引擎**
- 行为埋点：全站自动注入（inject.js）
- CDP：匿名访客 → 注册用户合并
- 转化漏斗：落地页 → 线索 → 订单
- 用户画像：360 度视图
- 数据看板：经营驾驶舱大屏

**社区与互动**
- 文章评论：支持点赞、置顶、审核
- 点评系统（大众点评）：网站/产品/书籍/活动四类点评 + 星级打分
- 社区投稿：会员 UGC → 审核发布
- 站内信：个人/多人/广播 + 业务事件自动触发
- 风控审核：规则引擎 + AI 辅助审核

**交易与交付**
- 课程系统：专栏/系列课/单课，学习进度追踪
- 1v1 咨询：时段预约 + 资格审核 + 付款 + 回放核销
- 直播：OBS 推流 + 卖课 + 聊天 + 回放转课程
- 付费订阅：会员计划 + 权益聚合
- 商城：虎皮椒支付 + 分销佣金

**运营支撑**
- 内容日历：排期 + 与文章发布联动
- 任务管理：团队协作
- NPS / 问卷：可视化构建 + AI 解读
- 通知渠道：企业微信/飞书/WhatsApp
- 积分系统：行为 → 积分 → 等级 → 权益

**系统管理**
- RBAC：多角色权限控制
- 健康检测：系统诊断
- 存储与性能：数据扫描 + 一键清理
- 操作日志：全量审计
- 数据导出：多格式

**生态扩展**
- PluginSystem：hooks/filters/actions 引擎
- 主题管理
- 远程市场同步
