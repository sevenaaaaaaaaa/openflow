# 后台 vs 前端 缺口盘点

> 目标：识别「后台已有功能，但前台还没有页面/入口」的缺口，给出补全优先级。
> 状态截至：2026-08

## 二、后台有功能、前端缺页面的缺口 ⚠️

### 高优先级（用户可直接使用的内容/转化类）

| 后台功能 | 现状 | 建议 |
|---|---|---|
| **资料下载 downloads** | 仅后端 API，前台无列表页 | [P0] 建 downloads.php 列表页（门禁表单 + 分类），入口加到导航 |
| **专题聚合 topics** | 后台可管理，前台无专题页 | [P0] 建 topics.php 专题聚合页，展示专题下的文章 |
| **活动 events** | 后台可管理，前台无活动页 | [P1] 建 events.php 活动列表/报名，与课程/咨询联动 |
| **文章分类/标签** | 后台可管理，前台无分类归档页 | [P1] 建 category.php / tag.php 归档页（SEO 价值高） |
| **Campaign 活动页** | 后台可配置，前台无落地页 | [P1] 复用 landing-pages 生成 campaign 落地页 |

### 中优先级（运营/用户成长类）

| 后台功能 | 现状 | 建议 |
|---|---|---|
| **会员等级/积分** | 后台有 gamification，前台仅 member.php?view=level 基础展示 | [P1] 完善等级页：积分明细、任务列表、升级路径 |
| **任务/内容日历** | 后台有 tasks/content-calendar，前台无 | [P2] 前台展示内容日历订阅或团队协作视图（内部用） |
| **订阅 newsletter** | 后台可管理，前台仅侧栏订阅框 | [P1] 建 newsletter 归档页（往期邮件列表） |

### 低优先级（内部/工具类，通常无需前台）

| 后台功能 | 说明 |
|---|---|
| CRM / CDP / 画像 / 线索 | 运营内部数据，一般不对公开前台开放 |
| SEO 全家桶 / 重定向 / 结构化数据 / 健康检测 | 技术运维类 |
| 邮件/短信/通知渠道/分发渠道 | 营销工具，无需公开页 |
| 自动化/画布/Campaign 配置 | 营销编排工具 |
| 数据导出/日志/权限/设置/插件/主题 | 系统管理 |
| 二维码/UTM/AB测试/转化组件/脚本 | 营销工具组件 |

## 三、建议的补全路线（结合「三流」主线）

1. **[P0] 资料下载页 downloads.php**：直接补内容流缺口（内容→门禁→线索），建议最快落地
2. **[P0] 专题聚合页 topics.php**：把已有的专题数据前台化，增强内容深度与 SEO
3. **[P1] 分类/标签归档页**：category.php / tag.php，低成本高 SEO 收益
4. **[P1] 活动页 events.php**：与咨询/直播/课程形成转化矩阵
5. **[P2] Newsletter 归档**：沉淀订阅内容

> 附注：文档中已列的计划是围绕三条主线（内容流/数据流/价值流），补前端页时应优先补「内容流」下游（下载/专题/分类），因为它们直接把已有后台数据变成可被用户消费与转化的前台资产。
