# OpenFlow XMP — 使用说明

> 从零开始，30 分钟上线一个自带增长能力的网站。

---

## 一、环境准备

- **最低配置**：PHP 8.0+、任意 Web 服务器（Nginx/Apache/Caddy），无需 MySQL
- **存储**：JSON 文件 + SQLite，开箱即用
- **推荐**：PHP 8.2+、Nginx、HTTPS

> 详细配置与运维要求见 [REQUIREMENTS.md](REQUIREMENTS.md)

### 快速启动

```bash
# 1. 将项目文件放入 Web 根目录
cp -r OpenFlow /var/www/openflow
# 2. 确保 data/ 目录可写
chmod -R 777 /var/www/openflow/data
# 3. 配置 Nginx 指向项目根目录
# 4. 访问你的域名，自动跳转 admin/login.php
```

## 二、登录与初始化

### 默认账号

| 用户名 | 密码 |
|--------|------|
| `admin` | 该账号名 + 2024（如 `admin` 密码为 `openflow2024`） |

### 首次登录后必须做的事

1. **修改密码** — 进入「系统设置 → 管理员列表」修改默认密码
2. **配置站点品牌** — 管理员列表 → 站点名称、标语、Logo、备案号
3. **运行健康检测** — 「运维工具 → 健康检测」确认所有组件正常
4. **配置 AI 供应商** — 「系统设置 → AI Agent 配置」填入 API Key
5. **配置 SMTP** — 「系统设置 → 邮件配置」填入发件服务器（表单通知 / 邮件营销依赖）

> 也可使用「首次引导（Onboarding）」向导，依次完成以上步骤。

## 三、核心工作流

### 流程 A：从零开始建站

```
① 站点结构 → 搭建一级/二级页面层级
② 文章管理 → 发布第一批内容（或批量导入历史文章）
③ 页面 SEO  → 为每个页面配置标题 / 描述 / OG
④ 结构化数据 → 注入 Schema.org 标记
⑤ Sitemap → 生成 sitemap.xml 并提交搜索引擎
⑥ IndexNow → 启用自动提交，加速收录
```

### 流程 B：搭建内容增长系统

```
① AI Agent 配置 → 连接你的大模型
② 知识库 → 上传公司/产品文档，建立 RAG 知识库
③ 内容日历 → 设定发布节奏
④ AI 选题 → 自动生成选题 + 内容大纲
⑤ AI 成文 → 一键生成文章，人工审校后发布
⑥ GEO 监控 → 关注 AI 搜索引擎是否引用你的内容
```

### 流程 C：搭建获客转化链路

```
① 落地页 → 可视化搭建一个获客页
② 表单 → 配置表单字段与感谢页
③ 资料门禁 → 上传可下载报告，设为「填表获取」
④ CRM 管道 → 设置销售阶段，自动评分
⑤ CDP → 查看访客画像，合并匿名→已知
⑥ 营销画布 → 创建自动化培育流程
```

### 流程 D：开通线上销售

```
① 商城设置 → 配置支付渠道（虎皮椒等）
② 课程管理 → 创建课程 / 专栏，设置价格
③ 付费订阅 → 创建会员计划
④ 1v1 咨询 → 添加咨询师，设定可预约时段
⑤ 直播 → 创建直播间，获取 OBS 推流密钥
```

### 流程 E：数据驱动运营

```
① 数据看板 → 查看实时 KPI 与转化趋势
② 转化漏斗 → 从落地页到订单的全链路分析
③ NPS 调研 → 发送满意度问卷
④ AI 周报 → Agent 自动汇总数据并给出建议
⑤ A/B 测试 → 对关键页面做对比实验
```

## 四、常见管理操作

### 文章管理
- **新建文章**：后台 → 文章管理 → 新建文章 → 支持 AI 辅助写作
- **批量导入**：后台 → 批量导入 → 选择来源（飞书/Notion/Obsidian）
- **定时发布**：编辑文章时设定发布时间即可

### 页面管理
- **页面编辑器**：后台 → 页面管理 → 选择页面 → 编辑
- **页面预览**：保存后点击预览查看效果
- **站点结构**：调整页面层级与导航顺序

### 线索与 CRM
- **查看线索**：后台 → CRM 线索 → 查看管道看板
- **跟进线索**：点击线索卡片 → 更新阶段 / 添加备注
- **自动评分**：管理员 → CRM 设置 → 配置评分规则

### 社区与内容审核
- **风控中心**：查看待审核评论 / 帖子 → 放行或拦截
- **AI 辅助审核**：一键 AI 判分 → 人工确认

## 七、自我进化（自生长）

OpenFlow XMP 会随你的使用生长，每个人最终长成不同的形态。

### 自我进化中心（`/admin/evolution.php`）

1. **立即扫描**：点击「🔍 立即扫描」让系统体检（或等 cron 每 6 小时自动扫）
2. **查看建议**：系统产出结构化建议，按「严重度 × 个性权重 × 复发 × 影响面」排序
3. **处理建议**：
   - **✅ 采纳**：标记已解决，系统复扫验证修复是否生效
   - **📋 转任务**：转为待办任务，融入团队协作
   - **🙈 忽略**：同类建议自动降权，减少打扰
4. **观察生长**：右侧「你的平台形态」会随使用变化（内容中心型 / 增长驱动型 / …）

### 协同修复中心（`/admin/safefix.php`）

1. **扫描生成方案**：系统找出可确定性修复的 bug，生成补丁 diff
2. **审核**：查看「原代码 vs 建议修改」，确认无误
3. **应用修复**：点「审核通过」，系统备份原文件后应用
4. **回滚**：应用后发现问题，一键恢复到修复前

> ⚠️ 安全原则：系统绝不自动改代码，人工确认是最后一道闸。

### 前台形态联动

- 学院页「🎯 为你推荐」会随站点形态动态调整推荐内容
- 形态画像决定推荐偏好（内容型偏文章、商业型偏转化、开发型偏 API）

## 八、安全注意事项

- 首次登录后**务必修改默认密码**
- 将 `data/` 目录放在 Web 可访问路径**之外**（或配置 Nginx 拒绝访问）
- 定期备份 `data/` 目录
- `.htaccess` 或 `nginx.conf.example` 已包含基本安全规则，部署时启用
