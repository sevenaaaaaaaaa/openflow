# 投放落地页

## `solo-growth.html` — 移动端信息流落地页

**转化动作**：留手机号（微信选填）换《一人公司增长手册》。

### 上线前必须做的一步

页面提交到 `/api/form-submit.php`，而那个接口要求**表单已存在且已发布**。
所以要先在后台建表单，否则页面会一直报「表单不存在」。

1. 后台 → 表单管理 → 新建表单
2. **slug 填 `solo-growth-handbook`**（和页面里 `FORM_SLUG` 一致）
3. 至少加两个字段：`phone`、`wechat`
4. **状态改成「已发布」**
5. 打开页面提交一次，确认后台能看到线索

改 slug 的话，页面里 `FORM_SLUG` 那一行也要同步改。

### 部署

放到站点任意可访问路径即可，例如 `/lp/solo-growth.html`。
纯静态，不依赖 PHP，可以直接上 CDN——但**接口必须同域**，
否则要在 `api/form-submit.php` 里放开对应的跨域来源。

### 投放链接带参数

页面会自动采集这些参数并随留资一起提交，用来回算渠道 ROI：

```
utm_source  utm_medium  utm_campaign  utm_content  utm_term  channel  aid  cid
```

例：

```
https://你的域名/lp/solo-growth.html?utm_source=douyin&utm_campaign=solo0901&aid=123
```

### 埋点漏斗

四段都埋了，可以直接看卡在哪一步（后台 CDP 事件里查）：

| 事件 | 含义 |
|---|---|
| `lp_view` | 落地页曝光 |
| `lp_form_view` | 表单进入视口（滑到了） |
| `lp_form_start` | 开始填写 |
| `lp_submit` | 点了提交 |
| `lp_success` / `lp_fail` | 成功 / 失败（失败带原因） |

**看漏斗的正确顺序**：曝光→滑到表单掉得多 = 首屏钩子不行；
滑到了但不填 = 资料价值没说清；填了但失败 = 接口或校验有问题。

### 页面结构（为什么这么排）

信息流用户是**被打断**的，注意力以秒计。所以：

1. **首屏一句话说清给谁**——「给一个人做公司的人」+ 痛点直击
2. **资料卡紧跟其后**——先把「你能拿到什么」具体化，再要联系方式
3. **表单在第一屏下方**，一滑就到；吸底条随时可跳回
4. 痛点 → 转折 → 证据 → 边界，是给**还在犹豫的人**看的，不是给所有人看的
5. **「先说清楚不适合谁」放在最后**——这一段看着像劝退，实际提高留资质量，
   而且是信息流投放里少见的诚实感，转化率通常不降反升

### 合规

- 表单下方写明了用途和「不会电话骚扰、随时可退订」——**别删**
- 只收手机号和选填微信，不多要一个字段。**每多一个必填字段，转化掉一截**
- 后台留资会自动进 CRM 并可触发自动化，注意配好退订链路
