一页纸介绍

别人的增长工具，默认你有一支团队。

芭乐派做的，是给没有团队的人的那一套。 内容、访客数据、自动触达、在线成交——一个系统，一个人跑得完。开源、免费、装在你自己的服务器上。

问题

一个人的公司买了这些工具隐含的前提
营销自动化你有市场团队 → 流程图画完了，没人去连
CRM你有销售团队 → 变成一个更贵的通讯录
数据分析你有分析师 → 报表很漂亮，看不出该干什么
建站工具你有开发和设计 → 页面做好了，然后没有然后了
五个工具，五份等着人来喂的工作。
而一人公司缺的从来不是工具，是人。

为什么是现在

AI 让「没有人」第一次不等于「做不了」。 芭乐派不做第六个等你来喂的系统——它自己干活：按你设的周期爬热点、出草稿、认访客、 提醒该跟进谁、巡检全站、算清哪个来源真的带来成交。

它一天替你干什么

你还没起床爬完行业热点，选题按优先级排好
你打开电脑三篇草稿等你改；昨天该跟进的 3 个人已经列好
你在忙交付认出老访客给他看更相关的内容；表单留资自动进 CRM
你下班之后巡检全站：哪页报错、哪页慢、哪块内容是空的
每周把「哪个来源真的带来成交」算给你

凭什么做得到 · 三样别人没有同时具备的东西

认得出人访客是谁、来过几次、在看什么。匿名 / 登录 / 换设备自动合并成同一个人
自己干活不是"加了个 AI 按钮"，是一个按周期自跑的增长引擎：选题 → 成文 → 巡检 → 优化
能被 AI 调用18 个 MCP 工具，整站内容与能力可被 Claude 这类 Agent 直接查询调用

WordPress、Segment、神策、HubSpot 各强一块，但没有谁三样都有， 更没有谁把它们和「一个人就能跑完」焊在一起。

边界 · 说清楚不适合谁

✅ 适合

  • 一个人（或两三个人）在做的公司、品牌、工作室
  • 内容驱动获客：写文章、做课程、接咨询、卖数字产品
  • 在意数据自主权，不想把客户名单交给别人的云

❌ 不适合

  • 已有成熟市场团队 + 数据团队的中大型公司——对你们我们是重复建设
  • 需要复杂多人审批流的组织
  • 想要像素级自由设计的品牌官网
